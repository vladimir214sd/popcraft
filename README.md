# PopCraft — 3D Pop-Up Cards & Wedding Invitations

Веб-витрина и интерактивный каталог объемных 3D-открыток ручной сборки с эффектом раскрытия («книжки-раскладушки»).

## 🌟 Реализованные возможности и блоки

### 1. Интерактивная 3D Pop-Up сцена (Hero)
- **Живая физика раскрытия**: створки открываются под углом от 0° до 110° при помощи плавных CSS 3D Transforms (`preserve-3d`, `rotateY`, перспективные тени).
- **Интерактивный ползунок угла**: позволяет пользователю вручную протестировать открытку в разном положении.
- **Многослойные векторные pop-up элементы**: вырастающие фигуры грибной полянки, цветущей сакуры, свадебной арки, праздничного торта и др.
- **Кнопка авто-анимации** с праздничным салютом конфетти.

### 2. Каталог открыток с фильтрами и живым 3D-тестом
- Категории:
  - 🍄 *Детские и сказки* («Лесная сказка & Грибная поляна», «Космическая одиссея»)
  - 🌸 *Любовь и годовщины* («Цветущая сакура & Белые журавли»)
  - 🎂 *День рождения* («Винтажный торт & Свечи», «Воздушный шар»)
  - 💍 *Свадьба и приглашения* («Изумрудная свадебная арка»)
  - 🐻 *Авторская серия* («Пермский арт & Медведь на Каме»)
  - 🏢 *B2B и корпоративные* («3D-эмблема & Архитектура»)
- Каждая карточка в каталоге реагирует на наведение и клик, распахивая 3D-створку прямо на витрине.
- Поиск по названию/поводу и сортировка по цене и популярности.

### 3. Интерактивный конфигуратор персонализации (CustomizerModal)
- Ввод имени получателя и личного текста с живым каллиграфическим превью на внутренней створке.
- Выбор дизайнерского конверта: крафт, изумруд, пудровый розовый, ночной сапфир.
- Выбор оттенка сургучной печати мастерской (золото, бордо, изумруд).

### 4. Блок доверия и краш-тест упаковки (Trust Bento)
- Закрывает ключевые страхи из интервью:
  - 🛡️ **Бронебойная упаковка**: трехслойный микрокартон с ребрами жесткости исключает замятие углов при доставке.
  - ⚡ **Срочная сборка**: отправка в течение 24 часов для подарков «в последний момент».
  - ✂️ **Лазерная микрорезка 0.15 мм**: плотный итальянский картон Fedrigoni 300–320 г/м².
  - 👐 **100% ручная сборка**: калибровка шарниров на 10 000+ циклов открывания.

### 5. Калькулятор тиражей для свадеб и B2B
- Устраняет проблему из интервью (типографии требуют от 40–50 шт):
  - Доступны тиражи от 15 штук.
  - Динамическая скидка до 45%.
  - Расчет стоимости за штуку, общего чека и срока готовности.
  - Бесплатный сигнальный образец в руки.

### 6. Корзина и демо-оформление заказа
- Управление товарами и количеством.
- Поддержка промокодов (промокод `POPCRAFT` дарит скидку 15%).
- Расчет доставки (бесплатно от 2000 ₽).
- Демо-оформление с генерацией номера заказа и сохранением истории заказов в `localStorage`.

## 🚀 Запуск проекта локально

```bash
# Установка зависимостей (уже выполнено)
npm install

# Запуск сервера разработки
npm run dev

# Сборка продакшн-бандла
npm run build
```

Сервер разработки доступен по адресу: **http://localhost:5173/**
